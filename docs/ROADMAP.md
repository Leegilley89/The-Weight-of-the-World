# Roadmap

Milestones indicate scope, not promised release dates.

## Milestone 0 — Community foundation
- [x] Public repository with MIT license
- [x] Founder-led governance and contribution policy
- [x] Game design document
- [ ] Recruit and appoint maintainers
- [ ] Set branch protection, labels, and an issue board

## Milestone 1 — First playable vertical slice
- [ ] Godot 4 project launches cleanly
- [ ] First-person movement and third-person toggle
- [ ] Object inspect, take, drop
- [ ] Empty/filled containers and inventory
- [ ] Ownership, theft, honor, and notoriety
- [ ] Basic hunger, thirst, and one crafting recipe
- [ ] One choice affecting morality and one unlockable ability
- [ ] Save/load basic player state
- [ ] Publish testing notes and reproducible build

## Milestone 2 — World simulation
NPC routines, witnesses, faction reactions, shelters, weather, persistence, and expandible region design.

## Milestone 3 — Public demo
Improve onboarding, accessibility, performance, testing, licenses, and community review.

## Milestone 4 — Kickstarter readiness
Demonstrable gameplay, credible scope and budget, reward and fulfillment plan, project risks, and creator rights documentation.
