# Contributing to The Weight of the World

Thank you for supporting this founder-led, community-developed survival RPG.

## Start here
1. Read README.md, GOVERNANCE.md, and docs/GAME_DESIGN_DOCUMENT.md.
2. Search existing issues before proposing a new feature.
3. For major changes, open a proposal issue and discuss the design first.
4. Fork the repository and work on a descriptive feature branch.
5. Submit a focused pull request explaining why the change helps and how it was tested.

## Contribution areas
- Godot/GDScript gameplay and tools
- Survival, crafting, inventory, containers, and world simulation
- Honor, witnesses, notoriety, and morality-gated abilities
- NPC behavior, dialogue, quests, and accessibility
- 3D art, animation, sound, writing, localization, and testing

## Code standards
- Target the Godot 4.x version documented in project.godot.
- Prefer small, modular scenes and scripts with clear names.
- Avoid breaking existing scene and save-data formats without a migration plan.
- Document new input actions, data models, and gameplay assumptions.
- Test changes locally; mention any untested behavior.
- Never commit credentials, private personal data, proprietary assets, or unlicensed content.

## Pull request checklist
- [ ] Linked issue or described motivation
- [ ] Fits the project vision
- [ ] Scope kept manageable
- [ ] Code style consistent and debug output removed
- [ ] Testing steps/results included
- [ ] Content ownership and licenses verified
- [ ] Screenshots or video added for visible changes, when applicable

## Licensing
By contributing code, you agree it can be distributed under the repository's MIT license. You must have the right to contribute it. Assets require explicit license information and founder/maintainer approval before merging. Do not import copyrighted game art, audio, or source code from other games.

## Respectful collaboration
See CODE_OF_CONDUCT.md. Critique proposals and implementations, not people. The founder makes the final decision on major disputed design questions.
